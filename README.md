# Лабораторная работа: Функции (Вариант 6)

## Автор
Иванова Ксения, группа ПИ-261

## Цель
Научиться выделять повторяющиеся вычисления в функции, передавать массив вместе с его размером и отделять ввод/вывод от вычислений.

## Описание
Программа находит сумму элементов массива R и сумму квадратных корней его неотрицательных элементов. Также программа отдельно считает и выводит количество пропущенных отрицательных элементов. Ввод и вывод осуществляются в функции `main`, а вычисления вынесены в отдельные функции.

## Исходные данные
Размер массива n (от 1 до 100) и сами элементы (по модулю не больше 1000).

## Ожидаемые результаты
Вывод трех значений: суммы элементов, суммы корней неотрицательных элементов и количества отрицательных элементов.
